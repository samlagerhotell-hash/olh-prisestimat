# OLH Prisestimat

Internal Oslo Lagerhotell price estimator (3PL, cross-docking), same prices and maths as the website.
`app/estimate.js` is a copy of the website's `src/estimate.js` (olh-website repo); the date in the footer says when it was taken.

- **Install:** Code > Download ZIP, unpack, double-click `Install.cmd` (copies `app/` to `%LOCALAPPDATA%\OLH Prisestimat`, desktop shortcut opens it as an Edge app window). See `LES MEG.txt`.
- **Prices change:** copy the website's `src/estimate.js` into `app/`, update the footer date in `app/Prisestimat.html`, commit and push.
